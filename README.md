# Homebrew tap

Apps by [Alexander Puschkin](https://www.puschkin.co), for [Homebrew](https://brew.sh).

```sh
brew install --cask alexanderpuschkinberlin/tap/mac-monologue
```

| Cask | App |
| :-- | :-- |
| `mac-monologue` | [Mac-Monologue](https://mac-monologue.puschkin.co) - record yourself, or your screen with you in it. Apple Silicon, macOS 15 or later. |

The first time you open Mac-Monologue, macOS stops it because the app is not
registered with Apple. Open **System Settings › Privacy & Security** and click
**Open Anyway** - once.

The cask is updated by the app's release script (`bin/publish` in
[Mac-Monologue](https://github.com/alexanderpuschkinberlin/Mac-Monologue)).
